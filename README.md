## 👨‍💻 About Me

<p align="justify">

I create and share Cheat Tables, Lua utilities, and Auto Assemble scripts, while also exploring game development tools and low-level programming concepts.

## 💫 What I'm Doing

- 🔭 Creating Cheat Tables (`.CT`) for PC games and improving memory-scanning workflows.
- 👯 Interested in collaborating on Unity modding projects, trainer development, and reverse-engineering tools.
- 🌱 Learning more about memory analysis, x86/x64 assembly, and Unity Engine internals.
- 💬 Ask me about Cheat Engine, pointer maps, AOB techniques, Lua scripting, and Auto Assemble.
- ⚡ I've been exploring game reverse engineering for over six years, and I share selected Cheat Tables on Fearless Revolution.
